# Apricot Orbit — free stylized skybox

An original 2048 × 1024 sunset panorama and six 512 × 512 PNG cube faces, by PLAYTEX AI. CC BY 4.0: commercial use and adaptation with attribution.

This is an authored sample with deterministic projection, not a screenshot or output from the AI skybox generator. It is an 8-bit LDR background, not a measured HDR lighting environment.

Three.js face order: px, nx, py, ny, pz, nz. This generic cubemap uses standard-dx orientation. Do not assume its pole rotations match Roblox. Review skybox.json and the [skybox guide](../../../guides/skybox-generator.md) before import.
