# Peach Ceramic — free PBR sample

Original PLAYTEX AI synthetic source plus seven 512 × 512 PNG maps. [License](../../../LICENSE): CC BY 4.0, including commercial use with attribution.

Upload source.png to the [PBR Map Generator](https://www.playtex.ai/pbr-map-generator) or use the included maps. Settings and provenance are in material.json. Normal is OpenGL (+Y); roughness is not smoothness. Albedo and emission are color/sRGB; all other maps are linear data. Emission is disabled. These are separate channels, not packed engine textures.

This is a stylized learning material, not a scanned or physically calibrated surface. Check tiling, scale, and shading in your target renderer.
